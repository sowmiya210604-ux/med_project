📊 DATA FLOW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

User Action → ReportExplorerProvider → State Update → UI Refresh

1. Select Category:
   ReportExplorerProvider.selectCategory(ReportCategory.lab)

2. Select Subcategory:
   ReportExplorerProvider.selectSubCategory(LabSubCategory.cbc)
   └─> loadReportsForSubCategory(reports, testResults)
       └─> Filter reports by test type
           └─> Convert to DetailedReportData
               └─> Update currentReports list
                   └─> notifyListeners()

3. Toggle Comparison:
   ReportExplorerProvider.toggleComparisonMode()

4. Select Reports:
   ReportExplorerProvider.toggleReportSelection(reportId)
   (Max 2 selections)

5. Generate Comparison:
   ReportExplorerProvider.generateComparison()
   └─> Get older and newer reports
       └─> Compare each parameter
           └─> Calculate status (Improved/Worsened/Stable)
               └─> Generate description
                   └─> Update comparisonResults
                       └─> notifyListeners()

🧪 COMPARISON ALGORITHM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Step 1: Determine baseline (older report)
Step 2: For each parameter:
   ├─ Check if both values exist
   ├─ If numeric:
   │  ├─ Calculate percentage change
   │  ├─ If change < 5% → STABLE
   │  ├─ If has normal range:
   │  │  ├─ Was abnormal → now normal? → IMPROVED
   │  │  ├─ Was normal → now abnormal? → WORSENED
   │  │  └─ Both abnormal → closer to normal? → IMPROVED
   │  └─ Else: INCREASED or DECREASED
   └─ If non-numeric: STABLE

Step 3: Generate description:
   "Improved - decreased by 12.5%"
   "Worsened - increased by 8.3%"
   "Increased by 4.2%"
   "Decreased by 15.7%"
   "No significant change"
